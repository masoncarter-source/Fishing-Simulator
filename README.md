# Stillwater

Stillwater is a small pixel-art fishing game set on a Yellowstone-inspired mountain lake.

Open `index.html` in a browser. There are no dependencies or installation steps.

Press Space or tap **Cast line**, wait for **Fish on!**, then press Space or tap **Reel in!**. Open the catch log to see fish counts and personal bests. Progress is stored in the current browser when local storage is available.
